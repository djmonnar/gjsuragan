# 출퇴근 태블릿의 오늘 예약

출퇴근 화면에 오너비스타가 수집한 네이버예약을 자동으로 표시한다. 최초 로딩, 화면 복귀, 인터넷 재연결, 한국 날짜 변경, 이후 1분마다 조회한다. 예약 조회는 별도 함수이므로 실패해도 출퇴근 처리는 계속된다.

## 표시 범위

- 서버에서 지정한 매장 한 곳의 한국시간 오늘 네이버예약만 조회한다. 날짜·매장 선택을 클라이언트에서 받지 않는다.
- 이름, 이용 시간, 어른·어린이 수, 메뉴, 상태를 표시한다. 직접 등록한 예약은 제외한다.
- 확정·신청·이용완료를 오늘 방문 건수/인원에 합산하고 취소·노쇼·알 수 없는 상태는 별도 접힌 목록에 표시한다.
- 전화번호, 결제금액, 요청사항, 내부 메모, 알레르기 답변은 전달하지 않는다.
- 네이버 수집 시각과 화면 확인 시각을 구분한다. 수집 후 15분이 지나면 오래된 정보임을 안내한다. 화면 새로고침이 네이버 수집 자체를 실행하지는 않는다.
- 수집 전, 연결 미설정, 조회 실패, 실제 예약 없음이 각각 다른 상태로 표시된다. 일시 실패 시 같은 날짜의 마지막 목록만 남기고 경고한다. 자정에는 전날 목록을 즉시 지운다. 연결 권한 거절 시 목록을 지운다.

## 구성

태블릿 → `attendanceBookingsApi` (등록된 기기 확인) → 오너비스타 `/api/integrations/attendance/today` (서버 전용 연결키 확인) → 기존 네이버예약 저장소.

오너비스타 변경은 `djmonnar/jit-pro`의 `codex/attendance-bookings` 브랜치에 있다. 로컬 작업 폴더는 `tmp/ownervista-attendance`이며 해당 폴더 전체를 궁중수라간 레포에 추가하지 않는다. 태블릿 변경은 궁중수라간 `codex/staff-attendance` 브랜치에 있다.

## 실제 예약 연결 전 설정

현재 로컬 미리보기는 **가상 예약**이다. 운영 환경 변수/연결키 생성, 실제 돌담명가 조직 매핑, 원격 게시 및 배포는 아직 하지 않았다.

1. 오너비스타 관리자에서 돌담명가의 실제 조직 ID와 연결된 네이버예약 매장을 확인한다. 네이버 플레이스 ID를 조직 ID 대신 입력하지 않는다.
2. 암호학적으로 안전한 32바이트 이상의 임의 연결키(base64url)를 만든다. 키는 소스나 채팅에 기록하지 않는다.
3. 오너비스타 서버 환경 변수 `ATTENDANCE_BOOKINGS_ORGANIZATION_ID`에 확인한 조직 ID, `ATTENDANCE_BOOKINGS_TOKEN_SHA256`에 연결키의 SHA-256 16진수 해시를 설정한다. 해당 조직의 네이버예약 모듈과 연동이 활성화되어 있어야 한다.
4. 궁중수라간 Firebase Secret Manager의 `OWNERVISTA_BOOKINGS_TOKEN`에 동일한 연결키 원문을 설정한다. 이 비밀은 `attendanceBookingsApi`에만 바인딩한다. 기존 `attendanceApi`에는 필요하지 않다.
5. 오너비스타 조회 API를 먼저 배포하고, 궁중수라간 `attendanceBookingsApi`와 정적 화면을 배포한다. 기존 출퇴근 기능의 최초 배포는 `staff-attendance.md`를 따른다.
6. 등록된 태블릿에서 실제 매장 이름과 오늘 예약을 오너비스타 화면과 대조한다. 표시 시각은 오너비스타의 기존 수집 주기에 따라 달라진다.

연결을 끊을 때는 오너비스타 해시를 삭제/교체하거나 네이버예약 연동을 끈다. 특정 태블릿은 admin에서 기기를 해제한다. 태블릿 인증은 서버의 최대 20초 메모리 캐시를 읽기 전에도 매 요청 확인한다. 예약 응답은 HTTP 캐시나 브라우저 저장소에 보관하지 않는다.

## 로컬 검증

`functions/scripts/preview-attendance.js`는 에뮬레이터 직원과 가상 예약만 사용하며 운영 데이터나 연결키를 읽지 않는다. 아래는 로컬 미리보기에서만 제공하는 장애 재현용 경로다.

`POST http://127.0.0.1:8766/preview-bookings-scenario?state=ready`

`state`는 `ready`, `error`, `empty`, `waiting`, `unconfigured`, `stale`을 지원한다. 다음 자동 확인 또는 브라우저 복귀 시 반영된다.

검증: 궁중수라간 예약 단위 테스트, 기기 인증 에뮬레이터 테스트, 정적 구문 검사, 오너비스타 피드 계약 테스트 및 변경 경로 타입 검사. 브라우저에서는 자동 표시, 갱신 실패, 예약 없음/수집 대기, 모바일·태블릿 배치와 출근 기록을 확인한다.
